오늘은 클로드 코드와 함께 이 블로그를 처음부터 만들었습니다. 프레임워크 없이 HTML, CSS, JavaScript만 썼는데, 덕분에 세 가지가 각각 무슨 일을 하는지 또렷하게 볼 수 있었습니다.

한 문장으로 정리하면 이렇습니다.

> HTML은 **뼈대**, CSS는 **옷**, JavaScript는 **움직임**이다.

## HTML: 무엇이 있는지 정한다

HTML은 페이지에 **어떤 내용이 어떤 순서로** 있는지를 정합니다. 제목, 문단, 링크, 이미지 같은 요소를 태그로 감싸서 표시합니다.

```html
<header>블로그 이름과 다크 모드 버튼</header>
<main>글 목록이나 글 본문</main>
<footer>저작권 표시</footer>
```

배운 점:

- `div`만 쓰지 말고 `header`, `main`, `article`, `footer` 같은 **의미 있는 태그**를 쓰면 화면 낭독기나 검색 엔진이 구조를 더 잘 이해합니다.
- `<meta name="viewport">` 한 줄이 없으면 휴대폰에서 페이지가 작게 축소되어 보입니다.

## CSS: 어떻게 보일지 정한다

CSS는 HTML 요소의 **색, 크기, 여백, 배치**를 정합니다. 같은 HTML이라도 CSS에 따라 전혀 다른 모습이 됩니다.

```css
:root {
  --bg: #ffffff;
  --text: #1f2328;
}

:root[data-theme="dark"] {
  --bg: #131416;
  --text: #e4e6ea;
}
```

배운 점:

- 색을 **CSS 변수**로 모아 두면, 다크 모드는 변수 값만 바꾸면 됩니다. 각 요소의 스타일을 일일이 고칠 필요가 없습니다.
- **모바일 우선**으로 작성하고 `@media (min-width: 640px)`로 큰 화면에 맞게 넓혀 가면 코드가 단순해집니다.
- 한글은 `word-break: keep-all`을 주어야 단어 중간에서 줄이 끊기지 않습니다.
- 폭을 `ch` 단위로 정했더니 글자 크기가 다른 푸터만 좁아지는 문제가 있었습니다. 레이아웃 폭에는 `rem`처럼 고정된 단위가 안전합니다.

## JavaScript: 무엇을 할지 정한다

JavaScript는 페이지가 **사용자의 행동이나 데이터에 반응**하게 만듭니다. 이 블로그에서는 이런 일을 합니다.

1. `posts/index.json`을 불러와 글 목록을 만듭니다.
2. 주소의 `#/post/...` 부분을 보고 어떤 글을 보여 줄지 정합니다.
3. 마크다운 파일을 읽어 HTML로 바꿉니다.
4. 다크 모드 버튼을 누르면 테마를 바꾸고, 선택한 값을 기억합니다.

```js
button.addEventListener('click', () => {
  const next = currentTheme() === 'dark' ? 'light' : 'dark';
  applyTheme(next);
});
```

배운 점:

- 브라우저는 `file://`로 연 페이지에서 `fetch()`로 다른 파일을 읽지 못합니다. 그래서 작은 **로컬 서버**가 필요했습니다.
- 사용자가 쓴 글을 화면에 넣을 때는 먼저 **HTML 이스케이프**를 해야 합니다. 그렇지 않으면 글 속의 `<script>`가 실제로 실행될 수 있습니다.
- 새로고침할 때 화면이 잠깐 밝게 깜빡이지 않게 하려면, 테마를 정하는 짧은 스크립트를 CSS보다 **먼저** 실행해야 합니다.

## 세 가지를 한눈에

| 언어 | 역할 | 이 블로그에서 하는 일 |
|------|------|------------------------|
| HTML | 구조 | 헤더, 본문, 푸터 같은 페이지 뼈대 |
| CSS | 모양 | 색, 글꼴, 여백, 다크 모드, 모바일 화면 |
| JavaScript | 동작 | 글 불러오기, 화면 전환, 테마 바꾸기 |

## 마치며

세 가지를 섞지 않고 **각자 맡은 일만 하도록 나누는 것**이 가장 큰 배움이었습니다. 덕분에 색을 바꿀 때는 CSS만, 화면 전환을 고칠 때는 JavaScript만 보면 됩니다.
